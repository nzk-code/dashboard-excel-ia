# 🏎️ Projeto Base — Dashboard de Vendas Porsche

> Dashboard de análise de vendas desenvolvida durante a **Aceleração de Excel com IA**.

## 📌 Sobre o projeto

Este projeto consiste na criação de uma **dashboard interativa de análise de vendas de veículos Porsche**, desenvolvida a partir de uma base de dados comercial.

O objetivo é transformar dados brutos em **informações visuais e indicadores relevantes**, facilitando a análise do desempenho das vendas.

A identidade visual da dashboard foi inspirada na linguagem **minimalista, sofisticada e esportiva da Porsche**, adaptando essa estética para uma experiência de análise de dados.

## 📊 Principais análises

- 💰 Valor total das vendas
- 🚗 Modelos mais vendidos
- 📅 Evolução das vendas por ano
- 📍 Distribuição das vendas por cidade
- 💳 Formas de pagamento mais utilizadas
- 📊 Quantidade de veículos vendidos
- 🔎 Filtros para exploração dos dados

## 🛠️ Ferramentas utilizadas

- **Microsoft Excel**
- **ChatGPT**
- **Claude Code**
- **Inteligência Artificial**
- **Tabelas e gráficos**
- **Tratamento e organização de dados**
- **Dashboard interativa**

## 🎯 Objetivo

Aplicar conhecimentos de **Excel e Inteligência Artificial** na construção de uma solução de análise de dados, transformando uma base de vendas em uma dashboard **visual, organizada e fácil de interpretar**.

## 🧠 O que foi praticado

- Organização e tratamento de dados
- Criação de indicadores
- Construção de gráficos
- Análise de dados comerciais
- Utilização de Inteligência Artificial como ferramenta de apoio
- Desenvolvimento de dashboards
- Apresentação visual de informações
